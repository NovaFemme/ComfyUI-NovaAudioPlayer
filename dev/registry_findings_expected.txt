# a finding that is not listed here fails the test, and so does a line here that
# no longer matches anything.
#
# Format, one finding per line:   file || rule || the line of code || why
# The line of code is matched with whitespace collapsed; line numbers are not
# used, so edits elsewhere in the file do not break the match.
#
# The installer (install.py, training/nova_ace_setup.py) is not listed because
# it is not published: both are in .comfyignore. On 2.6.1 they were nine of the
# 21 findings.
